One-time setup: Slack OAuth app

To use the "Install via OAuth" button, paste your Slack app's Client ID below (the Client Secret is optional). Sieve stores them and never asks again.

  1. Create a Slack app at api.slack.com/apps → From scratch.
  2. Under OAuth & Permissions, add bot scopes: channels:read groups:read users:read users.profile:read channels:history groups:history chat:write.
  3. Add this Redirect URL: https://localhost:19816/oauth/callback (replace localhost with your Sieve host).
  4. Enable PKCE under OAuth & Permissions and leave the Client Secret blank below — a localhost redirect is a "non-web URI" that Slack only allows via PKCE. (A Client Secret is only for a public-domain deployment.)
  5. Copy the Client ID from Basic Information and paste below.

After saving, the page reloads and the Install via OAuth button appears.
